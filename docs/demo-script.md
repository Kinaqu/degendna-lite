# 90-Second Demo Script

1. Problem: meme traders see token noise, but not wallet-specific fit.
2. Solution: DegenDNA turns wallet behavior into a personalized meme radar.
3. Connect wallet or use demo.
4. Reveal personality and Degen score.
5. Open radar and show momentum/risk/liquidity.
6. Inspect a token decision card.
7. Mint DegenDNA NFT on Base.
8. Show `hasMinted` unlock: fit scores, warnings, weakness report, watchlist.
9. Download PNG share card and open X share intent.
10. Explain frontend-only architecture: Birdeye browser calls, TypeScript scoring, Base NFT metadata.
