# 90-Second Demo Script

1. Problem: meme traders see token noise, but not wallet-specific fit.
2. Solution: DegenDNA turns wallet behavior into a personalized meme radar.
3. Connect wallet or enter a wallet address for preview mode.
4. In connected wallet mode, show the NFT mint dialog with wallet personality.
5. Mint DegenDNA NFT on Base or press Skip for hackathon access.
6. Open radar and show momentum/risk/liquidity/fit.
7. Inspect a token in the modal without leaving the radar.
8. Explain frontend-only architecture: Birdeye browser calls, TypeScript scoring, Base NFT metadata.
